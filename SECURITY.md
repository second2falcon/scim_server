# Security policy

## Supported versions

Only the latest release of SCIM Server gets security fixes.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub instead: go to the repository's **Security** tab and click **Report a vulnerability**.

Include what you found, how to reproduce it, and which SCIM Server and Nextcloud versions are affected. You'll get an acknowledgement within a week, and we'll keep you posted until it's fixed. Once a fix is released, the advisory is published, crediting you unless you'd rather not be named.

## Scope

In scope: this app's code, such as the bearer-token authentication, the SCIM endpoints and how they change Nextcloud accounts and groups.

Out of scope: vulnerabilities in Nextcloud itself (report them to [Nextcloud's bug bounty](https://hackerone.com/nextcloud)) or in your identity provider.
